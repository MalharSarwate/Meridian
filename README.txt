MERIDIAN — CURRENT WEBSITE ONLY

Open Meridian.html in your browser. The default view is Vidyavihar station to DBIT.

This single HTML contains the current purple frontend, application JavaScript and road datasets. It includes Resident/Planner views, local issue reporting, optional photos, proposals, feedback, referral preparation and export, map inspection, field notes and route comparison.

No old login.html, index.html, legacy planning dashboard, earlier design variants or Git history are included.

Internet access is required for MapLibre GL JS 5.6.1, map tiles and fonts. Reports and role switching are local demonstrations; no submissions are sent to government bodies.

For static hosting, upload Meridian.html. You can rename it index.html if you also replace internal Meridian.html links, or keep the filename and share its direct URL.

Road data: © OpenStreetMap contributors, ODbL 1.0. See https://www.openstreetmap.org/copyright . Embedded extracts include their source, retrieval date and bounding-box metadata. Building heights and routing assumptions remain visible in the app.
